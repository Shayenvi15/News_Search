About NewsSearch

NewsSearch is a lightweight API playground for retrieving structured news information based on user-defined search queries. The application combines a browser-based interface with a FastAPI backend and an external search API. Users can specify a topic, geographic location and language, while the backend processes the request and returns structured JSON results.
